SNIPER BATTLE 3D — онлайн-дуэль на двоих

ВАЖНО: это браузерная игра. На компьютерах не нужен отдельный EXE.
Для интернета сервер нужно разместить в сети (например, на Render или Railway).
Проект не публикуется автоматически — архив содержит исходники.

ЛОКАЛЬНЫЙ ЗАПУСК (Windows):
1. Установи Node.js LTS: https://nodejs.org/
2. Распакуй архив.
3. Открой папку проекта, в адресной строке Проводника набери cmd и нажми Enter.
4. Выполни:
   npm install
   npm start
5. Открой http://localhost:3000 в браузере.

ПОДКЛЮЧЕНИЕ ДРУГА:
Для игры через интернет:
1. Размести эту папку на Node.js-хостинге, который поддерживает WebSocket (например, Render или Railway).
2. Создай Web Service из проекта/репозитория; команда сборки: npm install; команда запуска: npm start.
3. Получи публичный HTTPS-адрес сервиса.
4. Отправь другу этот адрес.
5. Оба откройте адрес и введите одинаковый код комнаты (например, DUEL), затем нажмите «ВОЙТИ В БОЙ».
Не отправляй другу localhost — он работает только на твоём ПК.

Для проверки в одной Wi-Fi сети можно открыть игру на твоём ПК по адресу
http://IP-ТВОЕГО-ПК:3000 (разреши Node.js в брандмауэре Windows), а друг подключится
к этому адресу. Для игры через разные сети нужен публичный хостинг или настроенный туннель.

УПРАВЛЕНИЕ:
WASD — ходить; мышь — смотреть; ЛКМ — стрелять; зажать ПКМ — смотреть через оптику, отпустить — вернуться;
R — перезарядить; Shift — бег; Esc — отпустить мышь.

Примечание: это первый игровой прототип. Для простоты попадание подтверждается сервером
по выбранной цели, а не по полноценной физической баллистике. Лучше всего играть в
современном Chrome или Edge с включённым аппаратным ускорением.
